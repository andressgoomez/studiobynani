- (decision) Se elige Fast path para UX a partir del PRD y del relevamiento ya confirmado.
- (decision) La primera versión se especifica como web responsive con prioridad de uso en celular.
- (decision) El flujo principal de empleada es registrar una atención en pocos pasos.
- (decision) El flujo principal de NANI es revisar resumen diario, liquidaciones por empleada y cierre de caja.
- (decision) El acceso propuesto es selector de usuario + PIN corto; queda sujeto a validación.
- (decision) La persona que realiza la atención recibe el pago y el cierre calcula la entrega a NANI.
- (decision) Se incorpora el logo del estudio como referencia visual; la dirección usa rosa suave como superficie de marca y rojo como acento principal.
